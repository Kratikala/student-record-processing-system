# Student Management System using OOP

## Overview
A Python-based student management application built using Object-Oriented Programming (OOP). It allows users to manage student records, update information, generate performance reports, and store data persistently in a JSON file.

## Features
- Add and manage multiple student records
- Search students using their IDs
- Update student information
- Delete student records
- Calculate student averages and performance categories
- Generate an overall performance report
- Save and load data using JSON
- Handle invalid input and unsuccessful operations

## Used
- Python
- Object-Oriented Programming
- JSON
- Exception Handling
- Python Modules

## Concepts Demonstrated
- Classes and objects
- Encapsulation
- Modular programming
- File handling
- Data validation
- Exception handling

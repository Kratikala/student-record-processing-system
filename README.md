# Student Record Processing System

## Overview
A Python-based program for managing student records and analyzing academic performance.

## Features
- Store student details, marks, and attendance.
- Calculate each student's average marks.
- Determine pass or fail based on average marks.
- Identify the top-performing student.
- Filter students by attendance and average marks.
- Display a class summary.

## Used
- Python
- Lists and dictionaries
- Functions and loops
